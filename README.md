# ⚡ Renewable Energy Forecasting Using Deep Learning

## 📖 Description

This project presents an **AI-based Renewable Energy Forecasting System** that leverages both **Machine Learning** and **Deep Learning** techniques to accurately predict renewable energy generation from historical time-series data. The primary objective is to improve forecasting accuracy by capturing temporal patterns in energy production and comparing the performance of multiple predictive models.

The workflow begins with comprehensive **data preprocessing**, including data cleaning, handling missing values, and extracting time-based features such as **hour, day, month, and day of the week**. These engineered features help improve the predictive capability of the models.

Three forecasting models were implemented and evaluated:

- **Linear Regression**
- **Random Forest Regressor**
- **Long Short-Term Memory (LSTM) Neural Network**

Among these, the **LSTM model** effectively captures sequential dependencies in time-series data, making it particularly suitable for renewable energy forecasting. Its performance was compared with traditional machine learning models to determine the most accurate forecasting approach.

Model performance was evaluated using **Root Mean Square Error (RMSE)** and **Coefficient of Determination (R² Score)**, providing a quantitative comparison of prediction accuracy and model reliability.

# 📊 Model Evaluation

The forecasting models were evaluated using the following performance metrics:

- **Root Mean Square Error (RMSE)** – Measures prediction error.
- **R² Score (Coefficient of Determination)** – Evaluates how well the model explains the variance in the data.

These metrics enable an objective comparison between traditional machine learning algorithms and the LSTM-based deep learning model, helping identify the best-performing approach for renewable energy forecasting.
